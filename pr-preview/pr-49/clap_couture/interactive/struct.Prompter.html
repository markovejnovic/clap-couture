pub fn editor( &self, question: &str, extension: &str, initial: Option<&str>, ) -> Result<String, PromptError>

Ask in the user’s editor, in a temp file with extension, like md, that starts with initial. An empty answer reports the editor_empty message and cancels.

§Errors
  • PromptError::Cancelled when the user backs out or leaves the file empty.
  • PromptError::Signalled when the editor dies of a signal.
  • PromptError::Io when the editor cannot be found or started, or exits unsuccessfully.
