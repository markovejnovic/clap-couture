clap_couture

Struct Messages 

Source 
pub struct Messages { /* private fields */ }
Expand description

The text couture prints itself, for localizing it.

Set any of it with #[couture(messages = { ... })] on the type you parse, and on a nested type to reword the help of the commands it defines and those below them; each value takes an expression like Text. A heading message includes its trailing colon, since languages punctuate it differently: Usage:, 用法：, Utilisation :.

§Example

use clap::{Parser, Subcommand, ValueEnum};
use clap_couture::{Couture, CoutureParser as _};

#[derive(Parser, Couture)]
#[command(name = "tool")]
#[couture(messages = {
    none = "无",
    options = "选项：",
    usage = "用法：",
})]
struct Cli {
    /// 部署区域
    #[arg(long, value_enum)]
    #[couture(prompt)]
    region: Option<Region>,

    #[command(subcommand)]
    cmd: Cmd,
}

#[derive(Clone, ValueEnum)]
enum Region {
    Eu,
    Us,
}

#[derive(Subcommand, Couture)]
#[couture(categories = { "deploy" = { title = "部署：" } })]
enum Cmd {
    /// 部署当前项目
    #[couture(category = "deploy")]
    Ship,
}

Cli::couture_command().print_help().unwrap();

tool --help renders

用法：
  tool [OPTIONS] <COMMAND>

部署：
  ship  部署当前项目

选项：
      --region <REGION>  部署区域 [possible values: eu, us]
  -h, --help             Print help

and tool ship, run on a terminal without --region, asks for the optional region with none as its last choice. Picking it leaves region unset. With the interactive-cliclack backend:

◆  部署区域
│  ● eu
│  ○ us
│  ○ 无
└

Print help and [possible values: ...] are clap’s own text; for the help flag, disable clap’s and add your own.

pub const fn with_editor_empty(self, text: Text) -> Self

Reported when a #[couture(prompt, editor)] arg that is required or has a default is answered with an empty file. The default is "Aborting due to an empty answer.".

pub const fn with_editor_instructions(self, text: Text) -> Self

The last header line of the file of a #[couture(prompt, editor)] arg that is required or has a default. The default is "These lines are removed. Leave the file empty to cancel.".

pub const fn with_editor_instructions_optional(self, text: Text) -> Self

The last header line of the file of an optional #[couture(prompt, editor)] arg with no default. The default is "These lines are removed. Leave the file empty to leave it unset.".

pub const fn with_editor_not_utf8(self, text: Text) -> Self

The error a #[couture(prompt, editor)] file reopens with when it was saved in an encoding that can’t be read. The default is "The file is not UTF-8. Save it as UTF-8.".

Source

pub const fn with_editor_returned_early(self, text: Text) -> Self

Asked when the editor returned right away and left the file as it was, as code does without --wait. The default is "Your editor returned right away. Done editing the file?".

Source

pub const fn with_editor_unreadable(self, text: Text) -> Self

The error a #[couture(prompt, editor)] file reopens with while it still holds the U+FFFD marking text that couldn’t be read. The default is "Text that could not be read shows as \u{FFFD}. Retype it.".

Source

pub const fn with_editor_waiting(self, text: Text) -> Self

Shown while the editor is open; empty shows nothing. The default is "hint: Waiting for your editor to close the file...".

The heading above the env vars that pass a #[couture(secret)] arg, in --help. The default is "Environment:".

Source

pub const fn with_finish_hint(self, text: Text) -> Self

The hint beside each prompt for one more value of a multi-value arg, telling that an empty answer finishes the list. The default is "(<enter> to finish)".

Source

pub const fn with_none(self, text: Text) -> Self

The select option that leaves an optional prompted arg unset. The default is "(none)".

Source

pub const fn with_options(self, text: Text) -> Self

The heading above the options in --help. The default is "Options:".

Source

pub const fn with_selection_required(self, text: Text) -> Self

What a required multi-select tells the user when nothing is selected. The default is "Select at least one option".
