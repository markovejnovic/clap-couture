1//! Ask on the terminal for prompted args the user left out.
2//!
3//! Mark a field with `#[couture(prompt)]` to ask its help text, or `#[couture(prompt = "...")]`
4//! to ask something else. When the user leaves the arg out and stdin and stderr are terminals,
5//! [`CoutureParser`](crate::CoutureParser)'s entry points ask for it, then parse the answer as if
6//! it had been typed. Without a terminal, parsing behaves exactly like clap.
7//!
8//! ```
9//! use clap::Parser;
10//! use clap_couture::{Couture, CoutureParser};
11//!
12//! #[derive(Parser, Couture)]
13//! struct Cli {
14//!     /// Region to deploy to
15//!     #[arg(long)]
16//!     #[couture(prompt)]
17//!     region: String,
18//! }
19//!
20//! let cli = Cli::couture_parse_from(["deploy", "--region", "eu"]);
21//! assert_eq!(cli.region, "eu");
22//! ```
23//!
24//! A prompted arg that has a default is asked with the default pre-filled. An optional arg answered
25//! with nothing stays unset. An arg that takes many values, like a `Vec<T>`, is asked as a
26//! multi-select when it has possible values, and otherwise one value at a time until an empty
27//! answer. An arg passed on the command line or through its env var is never
28//! asked, and neither is one that conflicts with a passed arg or an earlier answer. An arg
29//! required through `required_unless_present` or a required `ArgGroup` is asked as required, and
30//! an empty answer is refused; in a group of prompted args, only the last one asked is. clap can't
31//! lift `required_unless_present_all` or `required_if_eq` from an arg, so when one of those
32//! fires, parsing fails with clap's error before anything is asked. Answers are not re-checked
33//! against `requires` and similar rules between args.
34//!
35//! `#[couture(confirm)]` on a `bool` flag the user left out asks whether to go ahead, after every
36//! other prompt, with each `{id}` in the question replaced by arg `id`'s value. A yes sets the
37//! flag; a no fails the parse. Without a terminal, the flag must be passed, as if it were required.
38//!
39//! # Answering in the editor
40//!
41//! With the `interactive-editor` feature, `#[couture(prompt, editor)]` asks in the user's editor
42//! instead, for text a single line can't hold. `editor(extension = "md")` names the temp file's
43//! extension, `txt` by default, so the editor highlights it.
44#![cfg_attr(feature = "interactive-editor", doc = "```no_run")]
45#![cfg_attr(not(feature = "interactive-editor"), doc = "```ignore")]
46//! use clap::Parser;
47//! use clap_couture::{Couture, CoutureParser};
48//!
49//! #[derive(Parser, Couture)]
50//! struct Cli {
51//!     /// Release notes
52//!     #[arg(long)]
53//!     #[couture(prompt, editor(extension = "md"))]
54//!     notes: String,
55//! }
56//!
57//! let cli = Cli::couture_parse();
58//! ```
59//! 
60//! The editor is found as git finds its own: `$VISUAL` (unless `TERM` says the terminal is
61//! dumb), then `$EDITOR`, then `vi`, and `:` takes the file as written. Its string is split into
62//! words like a shell would, so `EDITOR="code --wait"` works, but `~` and variables in it are not
63//! expanded. A known editor that returns at once, like `code`, gets the flag that makes it wait;
64//! any other that returns right away without touching the file is asked about before its answer
65//! is taken.
66//!
67//! The file opens with the arg's default, or the answer clap just turned down, above a header
68//! asking the question. The header's lines start with `#|`, so it comes back out while the
69//! user's own `#` lines, like markdown headings, stay. An empty file leaves an optional arg unset
70//! and aborts for a required one, like an empty commit message. It aborts for an arg with a
71//! default too, rather than quietly bringing the default back. The file is read in the encoding
72//! its byte order mark names, or as UTF-8, or else in the system's legacy encoding: the ANSI code
73//! page on Windows, the locale's elsewhere. A file in none of them reopens with an error.
74//!
75//! `editor` needs `prompt` beside it:
76#![cfg_attr(feature = "interactive-editor", doc = "```compile_fail")]
77#![cfg_attr(not(feature = "interactive-editor"), doc = "```ignore")]
78//! use clap::Parser;
79//! use clap_couture::Couture;
80//!
81//! #[derive(Parser, Couture)]
82//! struct Cli {
83//!     #[arg(long)]
84//!     #[couture(editor)]
85//!     notes: String,
86//! }
87//! ```
88//! 
89//! and an arg that takes a value; a flag has nothing to edit:
90#![cfg_attr(feature = "interactive-editor", doc = "```compile_fail")]
91#![cfg_attr(not(feature = "interactive-editor"), doc = "```ignore")]
92//! use clap::Parser;
93//! use clap_couture::Couture;
94//!
95//! #[derive(Parser, Couture)]
96//! struct Cli {
97//!     #[arg(long)]
98//!     #[couture(prompt, editor)]
99//!     follow: bool,
100//! }
101//! ```
102//! 
103//! # Secrets
104//!
105//! Add `secret` to ask for a [`secrecy::SecretString`] without echoing it. A prompted answer
106//! never reaches clap as plaintext; a value from the env var or an allowed command line is held
107//! by clap like any arg's. The arg refuses a value from the command line, where `ps` and shell
108//! history would see it; `secret(allow_argv)` allows it. A value from its env var is used without
109//! asking, and `--help` names the variable but hides its value. An `Option<SecretString>` field
110//! makes the secret optional: left empty, it stays `None`.
111//!
112//! Only [`CoutureParser`](crate::CoutureParser)'s entry points and
113//! [`couture_command`](crate::CoutureParser::couture_command) guard secret args; plain
114//! `Cli::parse()` or `Cli::command()` takes `--token` from the command line and shows its env
115//! value in `--help`.
116//! ```
117//! use clap::Parser;
118//! use clap_couture::{Couture, interactive::secrecy::SecretString};
119//!
120//! #[derive(Parser, Couture)]
121//! struct Cli {
122//!     /// API token
123//!     #[arg(long, env = "API_TOKEN")]
124//!     #[couture(prompt, secret)]
125//!     token: SecretString,
126//! }
127//! ```
128//! 
129//! `secret` modifies a prompt, so it needs one:
130//! ```compile_fail
131//! use clap::Parser;
132//! use clap_couture::{Couture, interactive::secrecy::SecretString};
133//!
134//! #[derive(Parser, Couture)]
135//! struct Cli {
136//!     #[arg(long)]
137//!     #[couture(secret)]
138//!     token: SecretString,
139//! }
140//! ```
141//! 
142//! A secret takes no default, which would be baked into the binary:
143//! ```compile_fail
144//! use clap::Parser;
145//! use clap_couture::{Couture, interactive::secrecy::SecretString};
146//!
147//! #[derive(Parser, Couture)]
148//! struct Cli {
149//!     #[arg(long, default_value = "hunter2")]
150//!     #[couture(prompt, secret)]
151//!     token: SecretString,
152//! }
153//! ```
154//! 
155//! and its field must be a `SecretString`:
156//! ```compile_fail,E0277
157//! use clap::Parser;
158//! use clap_couture::Couture;
159//!
160//! #[derive(Parser, Couture)]
161//! struct Cli {
162//!     #[arg(long)]
163//!     #[couture(prompt, secret)]
164//!     token: String,
165//! }
166//! ```

195/// Why a prompt produced no answer.
196#[derive(Debug, thiserror::Error)]
197#[non_exhaustive]
198pub enum PromptError {
199    /// The user backed out, which counts as Ctrl-C.
200    #[error("prompt cancelled")]
201    Cancelled,
202    #[error(transparent)]
203    Io(io::Error),
204    #[error("not a terminal")]
205    NotATerminal,
206    /// The editor died of this Unix signal, like Ctrl-C or the terminal closing. The prompt is
207    /// cancelled, and [`couture_parse`](crate::CoutureParser::couture_parse) dies of the same
208    /// signal, so a shell loop around the CLI stops too.
209    #[error("prompt cancelled")]
210    Signalled(Signal),
211}
212
213// `Interrupted` is the user backing out, `NotConnected` a missing terminal.
214impl From<io::Error> for PromptError {
215    #[expect(
216        clippy::wildcard_enum_match_arm,
217        reason = "`io::ErrorKind` is #[non_exhaustive]; every other kind is a plain I/O failure"
218    )]
219    fn from(err: io::Error) -> Self {
220        match err.kind() {
221            io::ErrorKind::Interrupted => Self::Cancelled,
222            io::ErrorKind::NotConnected => Self::NotATerminal,
223            _ => Self::Io(err),
224        }
225    }
226}

262    pub styles: CommandStyles<'prompt>,
263    /// The hint shown while the editor is open; empty shows none.
