Usage:
  interactive [OPTIONS] --app <APP> --region <REGION>

Options:
      --app <APP>            Application name
      --follow               Enable log following
      --region <REGION>      Application region [possible values: apac, eu, us]
      --replicas <REPLICAS>  Replica count [default: 2]
      --sidecars <SIDECARS>  Sidecars to run next to the app [possible values: logging, metrics, proxy]
      --vars <VARS>          Environment variables to set
  -h, --help                 Print help
