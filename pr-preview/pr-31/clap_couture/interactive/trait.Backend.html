Expand description

A terminal UI that can ask for one arg’s value.

Implement it to bring your own UI, or to answer from a script in tests.

fn editor( &self, prompt: &EditorPrompt<'_>, ) -> Result<Option<String>, PromptError>

Ask in the user’s editor, returning None for an empty answer. Whether an empty answer is allowed is decided by the caller, from prompt.optional.

The default opens the editor through EditorInteraction, asking with Backend::confirm whether the user is done when the editor returns right away. Override it to draw something around the editor, and use EditorInteraction from the override.

§Errors
  • PromptError::Signalled when the editor dies of Ctrl-C or of the terminal closing; PromptError::Cancelled on Windows.
  • PromptError::Cancelled when the done-editing question is cancelled.
  • PromptError::Io when the editor cannot be found or started, or exits unsuccessfully.
