> orbit --help
Deploy and manage your apps from the terminal, fashionably

Usage: orbit <COMMAND>

  logs      Tail live logs
  status    Show recent activity

Ship:     Get code to production
  deploy    Ship the current project
  promote   Promote a release to production
  rollback  Roll back to a previous release
  scale     Change the replicas count

Config:   What your app knows
  domains   Point a domain at your app
  env       Manage KEY=VALUE variables
  secrets   Manage environment secrets

Account:  Who you are
  login     Sign in to your account
  logout    Sign out of this machine
  whoami    Show who you're signed in as

  help      Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
>

> orbit deploy --help
Ship the current project

Usage: orbit deploy [OPTIONS] --app <APP> --region <REGION>

Options:
      --app <APP>            Application name
      --notes <NOTES>        Release notes, in markdown
      --region <REGION>      Region to deploy to [possible values: apac, eu, us]
      --replicas <REPLICAS>  Replica count [default: 2]
      --sidecars <SIDECARS>  Sidecars to run next to the app [possible values:
                             logging, metrics, proxy]
      --yes                  Skip the confirmation
  -h, --help                 Print help

Environment:
  ORBIT_TOKEN  Deploy token
