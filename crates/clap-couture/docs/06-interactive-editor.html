Ship the current project.

Usage:
  interactive [OPTIONS] --region <REGION>

Options:
      --follow
          Tail the logs afterwards

      --notes <NOTES>
          Release notes for this deploy

      --region <REGION>
          Region to deploy to

      --strategy <STRATEGY>
          How to roll the release out

          Possible values:
          - canary:  A slice of traffic first
          - rolling: One instance at a time
          
          [default: rolling]

  -h, --help
          Print help (see a summary with '-h')
