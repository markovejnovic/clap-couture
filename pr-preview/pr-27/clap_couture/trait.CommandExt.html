Extension trait adding categorized help to a [clap::Command].

Required Methods§

Source

fn with_couture<T>(self) -> Self
where T: Couture,

Group this command’s --help subcommand listing by T’s categories, with T’s Messages.

clap renders the arg sections as it always does, positionals and help_headings included. Everything below the usage goes in the command’s after_help, after any it already has; a before_help is kept. A help_template set before this call is kept too: place {after-help} in it rather than {all-args} or {subcommands}. Add args and subcommands before this call, as the listing is rendered here.

Leaves #[couture(secret)] args unguarded; take the command from CoutureParser::couture_command to refuse them on the command line.

§Example
use clap::{CommandFactory, Parser, Subcommand};
use clap_couture::{CommandExt, Couture};

#[derive(Parser)]
struct Cli {
    #[command(subcommand)]
    cmd: Cmd,
}

#[derive(Subcommand, Couture)]
#[couture(categories = { "everyday" = { description = "daily drivers" } })]
enum Cmd {
    /// Search your deployment history
    #[couture(category = "everyday")]
    Search,
}

let mut cmd = Cli::command().with_couture::<Cmd>();
assert!(cmd.render_help().to_string().contains("everyday"));
